# Afghan AI — User Guide

Afghan AI is a mobile-first learning platform prototype with Dari, Pashto, and English interface support.

## Getting started
1. Open the published Afghan AI website.
2. Open the main menu and select a section.
3. Choose Dari, Pashto, or English when the language control is available.
4. On a phone, refresh after a deployment if an older cached version remains visible.

## Important feature notes
- The AI Tutor requires a separately deployed backend; static GitHub Pages does not provide the /api/chat service.
- Sample learning content should be checked against approved textbooks.
- Browser-stored progress may not transfer to another device and can be lost if browser data is cleared.
- Do not enter passwords, financial details, or other sensitive information into prototype forms.
- A support or donation description does not itself mean online payment processing is connected.

## Reporting a problem
Mention the page, what you tapped, what happened, what you expected, and your device/browser. Do not share personal or confidential information.
