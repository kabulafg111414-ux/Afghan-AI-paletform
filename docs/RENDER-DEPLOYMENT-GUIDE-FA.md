# راهنمای راه‌اندازی Afghan AI در Render

این راهنما برای فعال‌کردن نسخهٔ هوشمند Afghan AI است. مراحل را می‌توان از آیفون نیز انجام داد.

## پیش از شروع
- به حساب GitHub دارای دسترسی به مخزن `kabulafg111414-ux/Afghan-AI-paletform` دسترسی داشته باشید.
- یک حساب Render بسازید یا وارد آن شوید.
- کلید API ارائه‌دهندهٔ هوش مصنوعی را از حساب رسمی همان ارائه‌دهنده تهیه کنید. هزینهٔ مصرف API جدا از میزبانی است و ممکن است قابل پرداخت باشد.

## راه‌اندازی سرویس
1. در مرورگر آیفون به [Render Dashboard](https://dashboard.render.com/) بروید و وارد حساب شوید.
2. گزینهٔ **New** و سپس **Blueprint** را انتخاب کنید.
3. حساب GitHub را وصل کنید و مخزن **Afghan-AI-paletform** را انتخاب نمایید.
4. Render فایل `render.yaml` را می‌خواند و سرویس `afghan-ai` را پیشنهاد می‌کند. تنظیمات و طرح رایگان/محدود آن را پیش از تأیید مرور کنید.
5. در تنظیمات Environment سرویس، متغیر محرمانهٔ `OPENAI_API_KEY` را اضافه کنید و کلید را فقط در فیلد Secret خود Render وارد نمایید.
6. مقدار `OPENAI_MODEL` به‌صورت پیش‌فرض `gpt-4.1-mini` است؛ آن را فقط در صورت آگاهی از سازگاری و هزینه تغییر دهید.
7. Deploy را اجرا کنید و منتظر تکمیل Build و Deploy بمانید.

## آزمایش
- آدرس سرویس ساخته‌شده در Render را باز کنید؛ نسخهٔ دارای Backend باید از همین آدرس استفاده کند.
- مسیر `/api/health` را باز کنید. پاسخ سالم فقط نشان می‌دهد سرور فعال است و آیا کلید تنظیم شده؛ موفقیت درخواست واقعی مدل یا وضعیت پرداخت را تضمین نمی‌کند.
- سپس معلم هوشمند و مترجم را با یک پرسش غیرحساس آزمایش کنید.
- GitHub Pages نسخهٔ ایستا است و به‌تنهایی مسیرهای Flask مانند `/api/chat` را اجرا نمی‌کند. برای قابلیت‌های هوشمند، از آدرس Render استفاده کنید؛ آدرس Pages را با آدرس Backend اشتباه نگیرید.

## امنیت و هزینه
- کلید API را هرگز در چت، فایل JavaScript، مخزن GitHub، تصویر صفحه یا پیام عمومی نفرستید.
- اگر کلید به‌اشتباه منتشر شد، فوراً آن را از ارائه‌دهنده باطل و کلید تازه ایجاد کنید.
- پیش از استفادهٔ عمومی، ذخیره‌سازی مشترک Redis/Valkey برای محدودیت درخواست‌ها، احراز هویت، نظارت، سیاست حریم خصوصی و محافظت ویژه از اطلاعات کودکان لازم است.
- طرح رایگان Render ممکن است محدودیت یا خواب خودکار داشته باشد و در هر زمان تغییر کند. هزینهٔ میزبانی و مصرف API را جداگانه بررسی کنید.
- هیچ‌گاه برای آزمایش از اطلاعات واقعی یا حساس شاگردان استفاده نکنید.

## وضعیت فعلی
این مخزن فایل پیکربندی Render را دارد؛ اما افزودن سرویس به حساب Render، تنظیم کلید محرمانه و Deploy نهایی باید در حساب مالک انجام شود. تا زمانی که این مراحل تکمیل نشده‌اند، قابلیت‌های AI در نسخهٔ Pages فعال محسوب نمی‌شوند.
