# Contributing to Afghan AI

Thank you for helping improve Afghan AI.

## Before making changes
1. Confirm the target repository and default branch.
2. Read the current implementation before editing it.
3. Keep changes focused; avoid replacing whole files when a small patch is sufficient.
4. Preserve navigation, Dari/Pashto/English support, responsive behavior, and accessibility.
5. Never commit API keys, passwords, tokens, or private user data.

## Pull requests
- Explain the user problem and proposed solution.
- List changed files and visible behavior changes.
- Include the tests actually run.
- Identify features that still need a backend or external service.
- Avoid unrelated formatting or redesign changes.

## Testing
Run available syntax and configuration checks. Manually test affected navigation and forms on mobile and desktop. Do not describe a check as passed unless it was actually run.

## Project boundaries
This is currently a static prototype. Accounts, cloud synchronization, AI provider access, payments, and privileged administration need a secure backend before production use.
